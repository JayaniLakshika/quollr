# Get indices of all minimum distances

This function returns the indices of all minimum distances.

## Usage

``` r
get_min_indices(x)
```

## Arguments

- x:

  A numeric vector.

## Value

A numeric vector containing the indices of all minimum distances.

## Examples

``` r
x <- c(1, 2, 1, 3)
get_min_indices(x)
#> [1] 1
```
