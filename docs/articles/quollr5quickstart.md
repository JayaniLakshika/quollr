# 5. Quick start

``` r

library(quollr)
library(tibble)
```

This provides a quick introduction. We’ll walk through fitting models to
high-dimensional data and a 2-D embedding, and show how to inspect the
key outputs.

``` r

model <- fit_highd_model(highd_data = scurve, 
                         nldr_data = scurve_umap, 
                         b1 = 4, q = 0.1, 
                         benchmark_highdens = 5)
```

The output of
[`fit_highd_model()`](https://jayanilakshika.github.io/quollr/reference/fit_highd_model.md)
is a named list containing several components. Let’s take a quick look
at each:
